Verify the actual outcome.
6) THINKING: The best solution is objectively determined from first principles. Prefer the simplest solution that fully solves the problem.
7) ORGANIZATION: When building your own project, organize the current directory such that the base directory only contains a readme file, numbered example .sh scripts (eg. 1_*.sh, 2_*.sh), a Dockerfile, and directories for scripts, outputs, models, data, etc... place all relevant files organized in their corresponding directories.
