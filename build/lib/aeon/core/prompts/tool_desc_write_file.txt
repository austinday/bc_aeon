Writes or overwrites an ENTIRE file from scratch. Creates parent directories if needed. Use this ONLY for: (1) creating new files, or (2) rewriting a file where more than ~50% of the content is changing. For small or targeted edits (fixing a bug, changing a few lines, updating a function), use str_replace instead -- it is faster, safer, and less error-prone.
Schema:
  file_path (str, required): Path to the file to write. Created if it does not exist; overwritten if it does.
  content (str, required): The complete file content. Prefix with "base64:" for base64-encoded content.
Example: {"tool_name": "write_file", "parameters": {"file_path": "test.py", "content": "__BLOCK_1__"}}
For multi-line content, use a "__BLOCK_N__" placeholder and write the actual content in a content block after the JSON. See RESPONSE FORMAT in your instructions.
