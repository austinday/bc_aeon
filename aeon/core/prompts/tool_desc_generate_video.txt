CRITICAL: MUST USE THIS TOOL for ANY video generation or manipulation request. Whenever the user asks you to make a video, animate an image, extend a video, or interpolate frames, you MUST call this tool. Do NOT write your own Python scripts, do NOT use curl, and do NOT try to interact with the ComfyUI API manually.
Generates or modifies high-quality video using the LTX-2.3 22B GGUF model via a local ComfyUI API and saves it to a specified file path (.mp4).
Schema:
  mode (str, required): The type of generation. Must be one of: 'text_to_video', 'image_to_video', 'video_extension', 'interpolate'.
  prompt (str, required): The detailed visual description of the video. Highly descriptive prompts work best.
  output_path (str, required): The absolute or relative file path where the resulting .mp4 should be saved (e.g., 'aeon_output/comfyui/video.mp4').
  input_path_1 (str, optional): The path to the starting image (for image_to_video) or video (for video_extension / interpolate). Required for those modes.
  input_path_2 (str, optional): The path to the ending image/video. Used only in 'interpolate' mode.
  width (int, optional, default=768): Video width. Must be divisible by 32.
  height (int, optional, default=512): Video height. Must be divisible by 32.
  frames (int, optional, default=33): Total frames. Best if divisible by 8 + 1 (e.g. 17, 33, 65).
Example (Text to Video): {"tool_name": "generate_video", "parameters": {"mode": "text_to_video", "prompt": "A futuristic city skyline at sunset, cars flying, dynamic motion", "output_path": "city.mp4", "frames": 33}}
Example (Image to Video): {"tool_name": "generate_video", "parameters": {"mode": "image_to_video", "prompt": "The dog runs across the field", "input_path_1": "dog.png", "output_path": "dog.mp4"}}
Example (Extend Video): {"tool_name": "generate_video", "parameters": {"mode": "video_extension", "prompt": "The car keeps driving into the sunset", "input_path_1": "car.mp4", "output_path": "car_extended.mp4"}}
