CRITICAL: You MUST use this tool for ANY video creation or manipulation request — making a video, animating an image, telling a visual story, putting a character into a scene, extending a clip, or restyling/editing a video. Do NOT write Python, use curl, or call the ComfyUI API yourself.

Generates or edits high-quality video with the LTX-2.3 22B model via local ComfyUI, saving an .mp4. ComfyUI is auto-started; this works from any directory.

Schema:
  mode (str, required): one of:
     'text_to_video'  — animate a text prompt from scratch.
     'image_to_video' — animate a single starting image (init_image) per the prompt.
     'keyframes'      — STORYBOARD: pin images at chosen frame positions; the model
                        interpolates/sequences between them. Use for "start as A, end
                        as B", multi-shot beats, or anchoring a consistent subject.
     'extend_video'   — continue an existing clip (init_video); seeds from its last frame.
     'edit_video'     — restyle/edit an existing clip (init_video) at `denoise` strength.
  prompt (str, required for most modes): detailed visual description; richer is better.
  output_path (str, required): where to save the .mp4 (absolute or relative).
  init_image (str): path to the start image — for image_to_video.
  init_video (str): path to the source video — for extend_video / edit_video.
  keyframes (list): for 'keyframes' mode, a list of {"image": path, "at_frame": int,
                    "strength": 0..1}. Place anchors across the timeline (frame 0 = start;
                    use frames up to ~ frames-1). strength 1.0 locks the frame hard.
  denoise (float, default 0.6): for edit_video — lower keeps more of the original (0.3
                    light restyle), higher changes more (0.8 heavy).
  negative_prompt (str): things to avoid.
  width (int, default 768) / height (int, default 512): auto-rounded to /32.
  frames (int, default 97): ~4s at 24fps; auto-coerced to 8n+1 (max ~121 per call —
                    for longer/multi-shot sequences, chain with extend_video).
  seed (int, default 42).

Composition guidance (you are the director — chain calls and assets freely):
  - Consistent character: create or obtain a character image, then reuse that SAME image
    as a frame-0 keyframe (or init_image) in each shot; or use edit_image to place the
    character in new scenes, then animate those. Use extend_video to continue across shots.
  - Storyboard a scene by passing several keyframes; render shot-by-shot and stitch.
  - For motion that follows a reference, animate from a strong init_image/keyframe.

Examples:
  Text:      {"tool_name":"generate_video","parameters":{"mode":"text_to_video","prompt":"a neon city at night, flying cars, dynamic camera","output_path":"city.mp4","frames":97}}
  Image:     {"tool_name":"generate_video","parameters":{"mode":"image_to_video","prompt":"the dog sprints across the field","init_image":"dog.png","output_path":"dog.mp4"}}
  Storyboard:{"tool_name":"generate_video","parameters":{"mode":"keyframes","prompt":"smooth cinematic motion between the moments","keyframes":[{"image":"hero_calm.png","at_frame":0},{"image":"hero_leaping.png","at_frame":96}],"frames":97,"output_path":"leap.mp4"}}
  Extend:    {"tool_name":"generate_video","parameters":{"mode":"extend_video","prompt":"the car drives off into the sunset","init_video":"car.mp4","output_path":"car_ext.mp4"}}
  Restyle:   {"tool_name":"generate_video","parameters":{"mode":"edit_video","prompt":"same scene in vibrant watercolor","init_video":"clip.mp4","denoise":0.5,"output_path":"clip_wc.mp4"}}
