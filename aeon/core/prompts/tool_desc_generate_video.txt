CRITICAL: use this tool for every requested video creation, continuation, edit, or final assembly. Do not call ComfyUI or ffmpeg yourself.

Generates verified H.264 MP4 video locally and returns it to Nexus as a playable chat attachment. The default `auto` renderer uses uncensored MiniMax H3 / 10Eros-Max NVFP4 with native synchronized stereo audio for ordinary generation, and the mature LTX-2.3 / 10Eros 1.5 Q8 specialist for explicit motion, arbitrary storyboard anchors, continuation, and editing.

Parameters:
  mode (str, required):
    - `text_to_video`: create from text.
    - `image_to_video`: animate `init_image` as the first frame.
    - `keyframes`: animate ordered image anchors. H3 supports first/last boundaries; LTX supports interior anchors.
    - `extend_video`: continue from the last frame of `init_video` (LTX).
    - `edit_video`: restyle/re-render `init_video` at `denoise` strength (LTX).
    - `concatenate`: assemble 2-20 ordered `input_videos`; no GPU or prompt needed.
  output_dir (str, required): destination DIRECTORY. Relative paths resolve from the current workspace; the tool chooses a collision-safe filename.
  prompt (str): the directed scene or H3 audiovisual IR.
  renderer (str, default `auto`): `auto`, `h3`, or `ltx`. Keep `auto` unless deliberately choosing a tradeoff.
  init_image (str): source path for `image_to_video`.
  init_video (str): source path for `extend_video` or `edit_video`.
  input_videos (list[str]): ordered compatible MP4 clips for `concatenate`.
  keyframes (list[object]): `{"image": path, "at_frame": int, "strength": 0..1}`. Use frame 0 and `frames-1` for H3 first/last conditioning.
  denoise (float, default 0.6): LTX edit strength; about 0.3 light, 0.6 balanced, 0.8 heavy.
  negative_prompt (str): visible failures/exclusions to avoid.
  width / height (int, default 864x480): divisible by 32. H3 supports up to 1344x768 or 768x1344; LTX is capped to a safe 768x512-area canvas.
  frames (int, default 124): H3 snaps upward to `17n+5`, 56-362 frames (about 2.3-15.1s). LTX snaps to `8n+1` and caps at 121 (about 5s). Both are 24fps.
  seed (int, default 42): keep fixed while revising one take.
  enhance (bool): true forces local model-native prompt compilation, false preserves the exact prompt, omitted compiles terse/unstructured prompts.

For H3, direct one sequence up to 15 seconds with this exact field order:
  `integrated_multimodal_description: [Shot 1] ...`
  `overall_soundscape: ...`
  `non_diegetic_music: ...`
Write later cuts as `[Shot N] At 00:SS.mmm, the camera cuts to...`; keep times inside the target duration. Describe composition, stable identity, visible action over time, camera motion, synchronized physical sound, and the final state. Format exact dialogue as `<d>[English] words</d>` and keep a stable speaker ID such as `(S1)`. The tool inserts required first/last-frame alignment instructions. A plain prompt still works, but the full IR gives better control.

For LTX, use one continuous untimestamped shot: initial composition, visible motion, performance/environment micro-motion, one camera move, final state, and continuity constraints. This fallback currently produces silent video.

For work over 15 seconds, render complete sequence clips and make `concatenate` the final video call. Reuse literal image anchors for identity. Trust only the successful typed receipt and inspect substantive final work with `analyze_video`.
