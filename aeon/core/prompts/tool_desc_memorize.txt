Stores a concise non-secret fact with explicit lifetime. Use only when the
fact will be useful after raw turn history is trimmed.

Never store passwords, tokens, cookies, private keys, recovery codes, raw account
credentials, or secret-bearing text. Nexus credential storage owns those values;
memory may contain only an opaque credential handle or “integration X is configured.”

Parameters:
- key (str, required): concise unique name.
- value (str, required): non-secret factual content.
- category (str, optional): descriptive grouping; default `general`.
- scope (str, optional): `task`, `project`, or `preference`; default `task`.
- ttl_hours (int, optional): 1–8760; omit when no expiry is appropriate.
