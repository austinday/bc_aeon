Applies a narrow atomic edit to an existing regular file.

Open the file first, copy a unique current SEARCH block, and pass its SHA-256
receipt. Exact or uniquely whitespace-normalized matching is the default. Fuzzy
matching is disabled unless explicitly requested; when enabled it still requires
a unique >=92% match. Python/JSON/YAML parse failures are rejected before write.

Parameters:
- file_path (str, required)
- expected_sha256 (str, required): 64-hex receipt from the current file
- Choose exactly one edit form:
  - patch (str): one or more `<<<< SEARCH ... ==== ... >>>> REPLACE` blocks; omit old_str/new_str
  - old_str (str): exact current text, with new_str (str, optional, default empty) as its replacement
- allow_fuzzy (bool, optional): default false

A failed match means re-open and diagnose current content. Never bypass it with a
blind overwrite.
