Makes targeted edits to a file using SEARCH/REPLACE blocks. Use this for ANY edit that doesn't require rewriting the entire file from scratch.
Schema:
  file_path (str, required): Path to the file to edit.
  patch (str, required): A string containing one or more SEARCH/REPLACE blocks.
Example: {"tool_name": "str_replace", "parameters": {"file_path": "src/main.py", "patch": "__BLOCK_1__"}}

In your content block, format the patch EXACTLY like this (you can include multiple blocks):
--- BEGIN BLOCK_1 ---
<<<< SEARCH
    def calculate_metrics(self):
        return sum(self.data)
====
    def calculate_metrics(self):
        return sum(self.data) / len(self.data) if self.data else 0
>>>> REPLACE
--- END BLOCK_1 ---

CRITICAL RULES:
1. The SEARCH block must EXACTLY match existing code (including leading indentation).
2. Include enough surrounding context in the SEARCH block to make it unique.
