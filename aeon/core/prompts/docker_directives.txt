**DOCKER & FILESYSTEM RULES**
1) **THE HOST BARRIER**: You are an agent running on the HOST machine. You have NO direct access to container filesystems.
2) **PATH TRANSLATION**:
   - HOST path: `/home/user/project/scripts/main.py`
   - MOUNT flag: `-v /home/user/project:/app`
   - CONTAINER path: `/app/scripts/main.py`
3) **TROUBLESHOOTING "FILE NOT FOUND"**:
   - IF a `docker run` command fails with "File not found":
   - **DO NOT** try to `ls` or `mkdir` the container path (e.g. `/app`) on the host. It will fail.
   - **DO** check your `-v` volume mount flags. Did you map the host directory correctly?
   - **DO** verify the file exists on the HOST at the source path.
4) **PERSISTENCE**: Containers are ephemeral. Always write outputs to a mounted volume (`-v host_dir:container_dir`).
5) **GPU USAGE**: Always use `--gpus all` or `--gpus '"device=0"'` when running GPU workloads.
