Atomically creates a new regular file or deliberately replaces an existing one.
For an existing file, `expected_sha256` is mandatory and must match the current
open_file receipt; otherwise the write is blocked. Prefer str_replace for narrow
edits. Python/JSON/YAML parse failures are rejected before replacement.

Parameters:
- file_path (str, required)
- content (str, required): complete text, or `base64:` followed by binary data
- expected_sha256 (str, required only when the file already exists)
