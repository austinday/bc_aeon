Opens a URL in a real, human-like browser (real Google Chrome, headed, stealthed via Patchright, with a PERSISTENT profile — so logins and cookies survive across steps and runs; if you logged into a site before, you are likely still logged in). Returns an observation AND attaches a screenshot of the page to your NEXT turn, so you SEE the rendered page directly, exactly as a human would — then act on it. The observation also lists the page's INTERACTIVE ELEMENTS as a stable numbered list you act on by [id], plus scroll state. You look at the picture and act by [id]. Use distinct tab_ids to keep several pages open at once.
Schema:
  url (str, required): The URL to open (scheme optional; 'https://' is added if missing).
  tab_id (str, optional, default="default"): A name for this tab (e.g. 'gmail', 'search'). Reuse the same tab_id with browser_interact/browser_read to keep working on that page; use browser_switch_tab to return to it without reloading.
  include_vision (bool, optional, default true): whether to attach the page screenshot to your next turn. Keep it on — you almost always want to SEE a freshly loaded page. Only set false in the rare case you're loading a page purely to act on a known element by [id] without needing to look.
  visual (str, optional, default "overlay"): which screenshot the model sees — 'overlay' = the render with small numbered [id] marks (best for acting precisely), 'clean' = the pure render with no marks (closest to a bare human view), 'both'.
Example: {"tool_name": "browser_navigate", "parameters": {"url": "https://mail.google.com", "tab_id": "gmail"}}
