Use the indexed elements and grounded visible text from the most recent browser observation. Element ids are observation-local and may be reassigned after any DOM change, so pass expected_text for every consequential element action and re-read or browser_find when state may be stale.

Canonical actions:
- click, double_click, right_click, hover: element_id; expected_text for clicks.
- type: element_id + text; optional clear_first and then_enter.
- press_key: key, with optional element_id.
- scroll: direction down/up/top/bottom/left/right/leftmost/rightmost/to_element; optional amount and element_id for a containing pane.
- select_option: element_id + value (visible label or value).
- check, uncheck, clear: element_id.
- drag: element_id + to_element_id.
- press_and_hold: element_id + duration in milliseconds.
- click_at, double_click_at, right_click_at, hover_at: x + y in the CURRENT screenshot viewport.
- type_at: x + y + text; optional clear_first and then_enter.
- drag_at: x + y + to_x + to_y; press_and_hold_at: x + y + duration.
- upload_file: element_id + host workspace file_path. Aeon privately stages the file into the browser container; expected_text is strongly recommended.
- go_back, go_forward, reload: no element.
- wait_for: optional text condition and duration timeout in milliseconds. The result explicitly says satisfied or timed out.
- get_text: optional element_id; read_text: no element.

Coordinate actions are a fallback for canvas, maps, remote desktops, and genuinely unindexed controls. Use coordinates only from the most recent screenshot, prefer a clean screenshot when marks could cover the target, and re-read after any layout/scroll change. The service rejects points outside the current viewport and reports the DOM target under the point. For any action that opens a native alert/confirm/prompt, optionally set dialog_action to auto, accept, or dismiss; set dialog_text when accepting a prompt. Destructive-looking confirms are dismissed in auto mode.

Accepted compatibility aliases: enter, select/choose/pick, wait, scroll_down/up/to_top/to_bottom/left/right/to_left/to_right. Prefer the canonical names above. A numeric legacy wait(text="5") is interpreted as a five-second pause.

After an action, use the returned URL, EVENTS, VISIBLE PAGE TEXT, validation state, element list, and screenshot as ground truth. If the result says NO CHANGE or wait:TIMEOUT, do not repeat the same action. Use browser_find to locate a control/text anywhere on the rendered page and browser_extract to inspect forms, links, tables, or long text structurally. Native dialogs and downloads are reported under EVENTS. External browser-engine evidence such as HTTP failures, failed XHR/fetch requests, console errors, and page crashes may also appear there.
