Interact with a specific element on the current webpage.

CRITICAL: You MUST use the 'element_id' provided in the list of interactive elements.
NEVER use CSS selectors, XPaths, or any other identifier.
The 'element_id' is the integer found in the red bounding boxes of the overlay image and the accompanying elements list.

STEALTH & SAFETY:
- SAFETY LOCK: Always provide the 'expected_text' parameter for critical clicks. The system verifies the element's text before acting to prevent VLM hallucinations.
- HUMAN-LIKE BEHAVIOR: The tool automatically uses Bezier curves for mouse movement. To maintain stealth, avoid rapid-fire interactions; use 'wait' if the page needs time to settle.
- SHADOW DOM: Elements inside Shadow DOMs are automatically indexed and can be interacted with using their `element_id` just like standard elements.

SUPPORTED ACTIONS:
- 'click': Standard click.
- 'type': Type text into an input.
- 'hover': Hover over an element.
- 'press_and_hold': Press and hold an element. Provide the duration in milliseconds using the 'text' parameter (e.g., '2000' for 2 seconds).
- 'enter': Press the Enter key.
- 'select': Select an option from a dropdown.
- 'scroll_down' / 'scroll_up': Scroll the page.
- 'wait': Wait for a specified number of seconds (provide seconds in 'text').

Parameters:
- action: The action to perform. Supported values:
    - 'click': Clicks the element. Use this for buttons, links, and custom dropdown triggers.
    - 'type': Types the provided 'text' into the element.
    - 'hover': Hovers the mouse over the element.
    - 'enter': Presses the Enter key on the element.
    - 'select': Specifically for native HTML `<select>` elements. Use the 'text' parameter to specify the label or value.
    - 'scroll_down': Scrolls the page down.
    - 'scroll_up': Scrolls the page up.
    - 'wait': Does NOT require an `element_id`. Pauses the browser for a specified number of seconds before taking the final screenshot. Use the `text` parameter to specify seconds (e.g. '5'). Extremely useful for bypassing CAPTCHAs, waiting for slow pages to load, or waiting for redirects to settle.
- element_id: (Required for most actions) The integer ID of the target element.
- text: (Required for 'type', 'select', and 'wait') The text to enter into the field, the option to select, or the number of seconds to wait.
- expected_text: (Highly Recommended) The text you expect the element to contain. Used as a safety check before clicking or typing.

STRATEGY FOR DROPDOWNS:
1. Check the element tag in the interactive elements list.
2. If the tag is 'select', use the 'select' action with the desired option text.
3. If the element is a 'div', 'span', or 'button' that looks like a dropdown, use 'click' to open it, then identify the 'element_id' of the desired option in the new overlay and 'click' that option.
