Marks the current task as complete and terminates the agent loop. Use ONLY after validating that the objective has been fully achieved (e.g., by running scripts and checking outputs, OR by fully answering an informational user query). 
Schema:
  reason (str, optional, default="Task completed."): A brief summary of what was accomplished and how it was verified.
Example: {"tool_name": "task_complete", "parameters": {"reason": "Built Docker image, ran tests, all 12 tests passed."}}
