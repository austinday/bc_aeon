Edits a file by replacing a range of lines identified by line numbers. Use the line numbers shown in OPEN FILES (the numbers before each '|'). The file MUST be open before editing so you can see the line numbers.
If you make multiple edits to the same file in one action batch, always use the ORIGINAL line numbers you see in OPEN FILES. The tool automatically adjusts for lines added or removed by earlier edits in the same batch. Edits must NOT overlap (do not edit a line range that was already edited in the same batch).
Schema:
  file_path (str, required): Path to the file to edit.
  start_line (int, required): First line to replace (1-indexed, matches OPEN FILES display).
  end_line (int, optional): Last line to replace (inclusive). Defaults to start_line (single line). Set to 0 to INSERT before start_line without deleting any lines.
  new_content (str, optional, default=""): Replacement text. Empty string deletes the line range.
Example (replace lines 15-20): {"tool_name": "edit_file_lines", "parameters": {"file_path": "main.py", "start_line": 15, "end_line": 20, "new_content": "def new_func():\n    return 42\n"}}
Example (insert before line 10): {"tool_name": "edit_file_lines", "parameters": {"file_path": "main.py", "start_line": 10, "end_line": 0, "new_content": "# New comment\n"}}
Example (delete lines 5-8): {"tool_name": "edit_file_lines", "parameters": {"file_path": "main.py", "start_line": 5, "end_line": 8}}
