Switch to an already-open tab (or a popup/OAuth window the browser captured) WITHOUT reloading it, and return a fresh observation of that tab. Preserves the page's live state (typed text, scroll position, session), unlike browser_navigate which reloads. Popup/login windows opened by a site appear in the "Open tabs" list as 'popup_N' — switch to one to drive it (e.g. a Google sign-in window).

Parameters:
- tab_id (str, required): the tab name (or 'popup_N') to switch to.
Example: {"tool_name": "browser_switch_tab", "parameters": {"tab_id": "popup_1"}}
