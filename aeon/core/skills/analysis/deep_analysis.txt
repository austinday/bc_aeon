# ANALYSIS SKILL: Quick Multi-Dimension Review
# USE THIS SKILL WHEN: you want a FAST, structured review and the heavier protocols do not fit
# -- i.e. it is NOT a deep codebase audit (use analysis/codebase_analysis) and NOT general
# topic research (use research/deep_research). This is the lightweight middle option: a quick
# multi-angle pass to surface observations without full dependency mapping or external domain
# research.
# If the task clearly involves analyzing a real codebase in depth, prefer analysis/codebase_analysis.
# If it clearly involves researching a topic with no codebase, prefer research/deep_research.

1. Identify 2-4 orthogonal angles on the subject and look at each briefly.
2. Note the most salient strengths, risks, and opportunities you can support with concrete evidence.
3. Synthesize into a short, prioritized set of observations or recommendations.
4. Deliver the full result via say_to_user (or write_file) BEFORE task_complete, then deactivate_skill.
