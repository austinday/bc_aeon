# SELF-IMPROVEMENT SKILL: Adding a New Capability (Tool or Skill)
# Triggered when extending Aeon with a new tool or a new skill protocol.
# Goal: a deterministic, fail-safe path from idea to live, verified capability.

1. DECIDE TOOL vs SKILL:
- A SKILL is reusable protocol TEXT (a procedure you follow). If the capability is "a better way to do X with existing tools," write a skill: a .txt at aeon/core/skills/<category>/<name>.txt. No code, no restart needed to author it (it is read at runtime), but you must verify it activates.
- A TOOL is executable behavior. If the capability needs new code/IO/an API call, write a BaseTool subclass under aeon/tools/.

2. FOR A NEW SKILL:
- Write the protocol with a clear structure (Objective, numbered Process steps, Verification).
- Place it at exactly aeon/core/skills/<category>/<name>.txt (create the category dir if needed). The SkillsManager relies on this path.
- Verify: expand_tool_category('<category>') to confirm it is listed, then activate_skill('<category>/<name>') to confirm it loads in full.

3. FOR A NEW TOOL (follow the adding_tools / adding_skills protocols and the gotchas):
- Inherit from BaseTool; call super().__init__(name=..., description=...). Avoid **kwargs in __init__ (the loader may treat them as missing deps).
- Implement execute(...); wrap it in try/except and return descriptive errors instead of crashing.
- Use absolute paths or PROJECT_ROOT; never assume the workspace contains the aeon source.
- Place the tool in aeon/tools/ (dynamic loader picks up BaseTool subclasses). If the loader rejects it due to constructor deps, manually instantiate it in aeon/main.py before register_tools.
- Add the tool name to the correct category in aeon/tools/categories.py if it should be collapsible.

4. VERIFY & GO LIVE:
- Follow the safe_self_modification skill: verify_self_modification with an objective that forces use of the new tool/skill, then restart_aeon, then a live test.

5. COMMON PITFALLS:
- "Tool Not Found": name in the BaseTool constructor must match the name being called; strip whitespace.
- Empty skill on activation: confirm the file is non-empty and at the exact category path.
